WHY THIS RUN IS EVIDENCE
Turn 003 justified `require_parameters: true` by one failure mode: it prevents a
silent downgrade to an endpoint that ignores response_format. This run shows the
other side of the same setting — an unsupported configuration failing
immediately, unambiguously, and for FREE.

Seven failures, zero tokens, 1.263 seconds. Without the setting these seven
calls would have been billed and would have returned prose.

It also exposed a coupling nobody had noticed: `require_parameters` restricts
routing to endpoints supporting EVERY parameter sent, so `response_format` was
silently deciding which models could be tested at all. That is a routing
constraint contaminating a model comparison, and it is why `--json-mode` exists.
