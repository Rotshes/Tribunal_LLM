A fictional proceeding

The Tribunal

Four advocates argue. Three judges rule, each by a different judicial method, each having read exactly the same arguments. The three rulings are reported side by side and are never combined.

The charge sheet

A case is a specification, not free text. It is validated before any model is called.

The panel

Seven model calls · about 35 seconds
Four advocates argue, in parallel
Three judges rule on those arguments

The arguments

Each advocate puts the case for its seat, whatever it personally concludes. None saw the others.

The rulings

Three judges. Identical input. None saw the others.

These opinions are reported separately. The Tribunal produces no majority, headline, score or single result — the disagreement is the output.
